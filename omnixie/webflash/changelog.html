Firmware Changelog

Version history for the Omnixie Clock Wi-Fi (ESP8266) firmware

Back to Firmware Flasher
This is the Wi-Fi (ESP8266) firmware version, shown on the web Dashboard status page and in the serial log (from v2.2 it prints Firmware vX.Y). It is different from the version on the tubes / remote menu, which is the display (STC) firmware and is not changed by flashing over Wi-Fi.

v2.3

2026-08-30

Fixed The SoftAP hotspot SSID is now always padded to 6 hex digits so it matches the serial number (SN) printed on the label. Previously a unit whose first serial byte was below 0x10 (about 6% of units) got a 5-digit SSID (for example SN 08EB79 became Omnixie_8eb79), which prevented the companion app from deriving the correct SSID from the SN. The SSID is now always Omnixie_ + the full 6-digit ID.

v2.2

2026-08-30

Added Companion-app captive-portal suppression (GET /api/appmode?on=1|0). In app mode the clock answers the operating system's connectivity check with a "has internet" reply (Apple Success / Android 204 / Windows NCSI), so no captive setup page pops up and the app drives the whole setup. The default keeps the pop-up so the traditional manual setup flow is unchanged.

Added The Wi-Fi setup page now shows the firmware version at the bottom (read live from the device).

v2.1

2026-08-30

Added Companion-app provisioning API (no password required while the clock is in setup / hotspot mode): GET /api/info, GET /api/scan, GET /api/provision.

Fixed Wi-Fi setup over the clock's hotspot no longer requires the Dashboard password. This fixes the case where, once a Dashboard password had been set, the setup page could not scan for networks or save Wi-Fi settings.

Changed Updated the serial boot banner: copyright year 2024 to 2026, "Designed by Zeyuan Yan & Aiden Fang", email removed, shows both omnixie.cn and omnixie.com, and prints the firmware version.

v2.0

2026-08-30

Fixed Factory reset from the remote now truly clears the Wi-Fi settings and the Dashboard password. Previously, if a Dashboard password had been set, the reset silently kept the saved Wi-Fi/password. On the remote (turn the display off with POWER first): 9434 OK = full reset including Wi-Fi and password; 4648 OK = keep Wi-Fi, reset everything else.

v1.1.5

2024-04-03 - original baseline

Original release by Zeyuan Yan. Wi-Fi Nixie clock firmware with NTP time sync, web Dashboard configuration, OTA update, and remote control.
