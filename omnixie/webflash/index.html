Firmware Flasher

Update your Omnixie Clock from the browser - no software to install

Back to Omnixie Clock
Use Google Chrome or Microsoft Edge on a computer. Safari and Firefox are not supported.
请在电脑上用 Chrome 或 Edge 浏览器打开本页。Safari 和 Firefox 不支持。
Your browser does not support Web Serial. Please use Chrome or Edge. 当前浏览器不支持 Web Serial，请改用 Chrome 或 Edge。 This page must be served over HTTPS. 本页需通过 HTTPS 访问。

Steps / 操作步骤

  1. Connect the clock to your computer with a USB-C cable.
    用 USB-C 线把时钟连到电脑。
  2. Close any serial monitor (CoolTerm, Arduino, screen) that might hold the port.
    关闭占用串口的程序（CoolTerm、Arduino、screen 等）。
  3. Click Install above, then pick the serial port named like usbserial / CH340 / USB-SERIAL.
    点上面的 Install，在弹窗里选名字带 usbserial / CH340 的串口。
  4. Wait for it to finish and reboot. Done.
    等待烧录完成并自动重启即可。

Notes / 说明

  • Your clock settings (Wi-Fi, alarms) are kept. This updates the program only.
    烧录只更新程序，Wi-Fi、闹钟等设置会保留。
  • Windows: if no port appears, install the CH340 driver from WCH, then replug.
    Windows 若看不到串口，请安装 WCH 的 CH340 驱动后重新插拔。
  • macOS: recent versions work without a driver.
    macOS 新版本一般免驱动。
